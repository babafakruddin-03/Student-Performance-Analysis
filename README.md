# Student Performance Analysis

## Project Overview
This project analyzes student academic performance using Python,
Pandas, MySQL, and data visualization.

It calculates average marks, identifies the highest-performing
students, analyzes pass/fail results, and identifies students
with low attendance.

## Technologies Used
- Python
- Pandas
- MySQL
- SQL
- Matplotlib
- VS Code

## Features
- Student data management
- Average marks calculation
- Highest-performing student identification
- Pass/fail analysis
- Attendance analysis
- Student performance charts
- MySQL database integration

## Project Structure
- data/: Contains student CSV data
- src/: Contains Python source code
- reports/: Contains generated charts

## How to Run
1. Install Python.
2. Install the required Python libraries.
3. Configure your MySQL database connection.
4. Run the Python program.
